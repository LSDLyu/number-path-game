# 单词与玩法更新（2026-09-20）

本轮保留十关、每个字母出现两次的分配，加入52个儿童例词。每个字母第一次随机选词，下一次避开刚出现的词。卡片分别显示字母、英文单词、对应中文意思和图片；原26词用手绘图，新增26词用彩色表情插图兜底。

语音只读选中的单词。当前发布版使用设备英语语音，优先选择自然或增强音色，采用正常音高和0.95语速。尚未接入OpenAI配音，也没有成功下载自然人声录音。不能把本版本描述成ChatGPT配音版。接入OpenAI Developers后，可生成单词录音并在界面注明AI配音；不需要改变游戏机制，也不能把API密钥放进前端。

`dist/audio/manifest.js` 只应列出实际存在且获授权的录音。目前为空，不会发出不存在的MP3请求。已实现预载、Web Audio播放、超时/失败时设备语音兜底，以及静音和换关时取消。`tests/prepare-word-audio.py` 是可选的授权词典录音准备脚本，本轮下载超时；运行后须复核音频内容和credits.json版权信息再发布。

## 各关操作

| 关卡 | 主要玩法 |
| --- | --- |
| 1 字母森林 | 跳火炉、弹簧、隧道，顶字母或站上后跳落收集 |
| 2 滚滚球谷 | 站球上左右滚动、跳跃收字母 |
| 3 字母陨石雨 | 移动并升降篮子，接字母、躲石头 |
| 4 彩虹泡泡海 | 上键吹泡泡击中字母，也可驾驭泡泡 |
| 5 星光字母列车 | 跳上移动火车，下键盖车票章 |
| 6 云朵升降桥 | 上下键呼叫附近云朵，空中上键滑翔 |
| 7 蘑菇弹跳园 | 蘑菇自动弹跳，下键站稳 |
| 8 小船漂流记 | 登船左右划船，下键放鱼线钓字母 |
| 9 气球花园 | 气球四向飞行，穿过字母圈 |
| 10 彩虹礼物城 | 下键点亮六把钥匙，上键打开礼包 |

最后礼包打开时镜头对准Lisa与礼包，播放持续的A–Z字母烟花和彩纸，七秒后才出现通关面板。重新开始会清除烟花和延迟回调。

## 验证及发布

`tests/game-regression.cjs` 运行实际内联脚本、事件和Canvas，检查十关依次完成、五按钮/键盘、长短跳、多指输入、血量、字母分配、配图、不同收集机制、烟花及声音取消。测试不是iPad实机音质听测。
