# 界面与交互评审

2026-09-12。基于当前游戏源码、线上界面检查和浏览器交互规范；没有进行玩家访谈，也没有把推测写成用户研究结论。

## 发现与改动

| 当前问题 | 本次处理 | 目的 |
| --- | --- | --- |
| 标题、常驻选题表和手记分散注意力；桌面基线中棋盘顶部距视口顶部约 526 CSS 像素 | 保留简短规则，棋盘居中；选关、设置、帮助使用独立面板 | 让玩家更早看到任务和棋盘，减少主界面的信息量 |
| 手机隐藏语言入口，操作分散 | 保留语言切换；撤回、提示、重开紧邻棋盘；按钮采用至少 44 像素的主要触控区域 | 降低查找与误触成本 |
| 快速移动的指针可能一次跨过多个格子 | 直线段补齐中间格，支持时读取 coalesced pointer samples | 降低快速滑动漏格；不猜测缺失的对角转弯 |
| 只能单步撤回，重开容易误触 | 点回已走格可回到该处；重开先确认；保留原有单步撤回 | 方便修正，减少意外丢失当前路线 |
| 切换类别回到开头，刷新丢失本次计时 | 每类记住题号；保存累计活动时间；面板和后台暂停 | 保持游戏上下文，避免把离开页面的时间计入成绩 |
| 提示仅与一条预设答案比较 | 根据当前前缀限量求解；超时返回未知；提示带行列坐标 | 提示依据是路线可行性，辅助读屏定位 |

所有类别仍独立按顺序解锁，完成反馈、开关和旧存档继续保留。当前关卡计时保存在原有本地进度对象中；没有新增分析服务或外部数据收集。

## 设计依据

- [W3C：Target Size (Enhanced)](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html) 给出 44×44 CSS 像素的增强触控目标。这里把它用于主要操作和选题按钮；这不是对整个游戏作无障碍等级认证。
- [WAI：Dialog (Modal) Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) 描述模态面板的焦点、键盘和关闭行为。本次使用浏览器原生 `dialog`，关闭按钮可见，面板有独立标题。
- [MDN：getCoalescedEvents](https://developer.mozilla.org/en-US/docs/Web/API/PointerEvent/getCoalescedEvents) 解释浏览器可能合并移动采样，以及如何恢复更细的输入轨迹。该接口并非所有浏览器支持，代码进行能力检测，缺少它时仍处理普通指针事件和直线补点。
- [MDN：Page Visibility API](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API) 提供页面隐藏与恢复事件，用于暂停计时、取消后台动画和提示计算。

## 取舍与限制

- 手机采用按需展开的底部面板，桌面使用居中面板。菜单打开期间暂停计时，关闭后返回当前路线。
- 棋盘同时考虑视口宽度和高度，给下方操作留出空间；可用宽度足够时不缩到 268 CSS 像素以下，使 6×6 单格仍有 44 像素的触控区域。极短屏幕保留滚动，不继续压缩格子。
- 求解在独立 Worker 中执行，最多搜索 100,000 个节点，界面另设 1.5 秒截止。没有 Worker 时降为 5,000 个节点。搜索预算耗尽表示未知，不表示路线错误；标准解前缀不需要启动 Worker。
- 自动死路反馈仍只检查眼前有无合法下一步，不会每走一步就做完整求解。这样避免把沉重的计算放入连续触控中。
- 进度属于当前浏览器；清除网站数据会清除存档。存储写入失败时显示说明，仍允许继续游戏。
- 不为游戏增加排名、倒计时惩罚、声音或额外的持续动画；先保证路径操作、反馈和恢复可靠。

## 验证

- 43 项测试通过，其中原有测试覆盖全部 319 题的标准路径、四种棋盘、庆祝效果、减少动态效果和顺序解锁。
- 新增交互测试覆盖面板显示、取消重开、类别位置恢复、回退、键盘单入口、直线快速拖动、多指针与取消、合并采样的转弯、提示结果过期、超时、后台和面板暂停、计时恢复及存储失败。
- 求解器使用不共享剪枝逻辑的 3×3 穷举参考实现比对合法前缀，并验证多解示例的两种合法路线和全部题目的后段前缀。多解示例为测试构造，不声称题库中的关卡存在多个答案。
- 浏览器检查用于验证原生面板、真实指针事件和上线资源；响应式样式与 jsdom 测试不能替代真机的拖动手感、Safari 行为及硬件震动确认。

## 建议下一轮优先做

1. 邀请几位首次接触游戏的玩家完成一题，观察是否理解“最大数字最后到达”，再决定是否需要一次性的图示引导。
2. 真机分别体验小屏 iPhone 和 Android 的 6×6 连线，重点观察边缘转弯与单手操作。
3. 如果玩家经常跨浏览器游玩，再加入明确由玩家触发的存档导入、导出；目前不引入账号系统。
